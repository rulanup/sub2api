# 错误与限流

Sub2API 保留上游协议的错误结构，并在网关层返回认证、路由和限流错误。

## 常见状态

| 状态 | 含义 | 建议 |
| --- | --- | --- |
| 400 | 请求格式或参数无效 | 检查 JSON、模型和必填字段 |
| 401 | 认证失败 | 检查 Bearer Key、有效期和权限 |
| 403 | 当前 Key 无权限 | 检查分组、模型白名单和账号状态 |
| 404 | 路径或模型不可用 | 检查版本、路径和模型名称 |
| 429 | 速率限制 | 降低并发并读取 Retry-After（若存在） |
| 5xx | 上游或网关异常 | 使用 Request ID 查询诊断信息 |

## 限流

429 通常来自 Key、分组、渠道或上游供应商的限制。不要通过提高并发绕过限流。尊重服务端返回的等待时间，并使用指数退避处理暂时错误。

## 排查顺序

1. 在 Debug Center 查看状态、耗时和脱敏后的响应。
2. 对照 API Reference 检查路径和参数。
3. 检查 Key 所属分组是否允许当前模型。
4. 如果错误来自浏览器 Live 模式，确认目标支持 CORS。
